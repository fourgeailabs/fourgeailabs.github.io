# FourgeAI LABS — Showcase Site

The public showcase website for FourgeAI LABS (DevForge Pro): all apps and games
for Android, macOS and Windows, in one place.

- Live: https://fourgeailabs.github.io
- Hosting: GitHub Pages (free), served from this repo's `main` branch.
- Stack: a single self-contained `index.html` — no build step, no dependencies.

To update the site, edit `index.html`, commit, and push; Pages redeploys
automatically within a minute or two.
